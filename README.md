# Belgium Campus Open Day

Start here: open `MAUIProject/BCOpendayApp/BCOpendayApp.sln` in Visual Studio with the .NET 9 MAUI workload, restore packages, select Windows Machine or an Android device and run. The app is the improved frontend with the poster-inspired black, red and yellow design.

Read the app README and TEST_CHECKLIST for setup and verification. Build and device execution have not been verified in this environment.

Included: one MAUI app, the supplied Unity project and the original Android binding. The Unity project is a starter scene and is not an embedded AR tour. See INTEGRATION_NOTES.md for the precise integration status.
